# مشروع تطبيق المصحف المعلم للصغار للأندرويد (Flutter)

تم تطوير هذا المشروع ليكون مماثلاً لتطبيق "المصحف المعلم للصغار" المتوفر على iOS، مع تحسينات في الواجهة واستخدام تقنية **Flutter** لضمان السرعة والسلاسة.

## 🌟 المميزات الرئيسية
*   **المصحف المعلم:** تلاوات تعليمية (مثل الشيخ المنشاوي والحصري) مع ترديد الأطفال لتسهيل الحفظ.
*   **تكرار الآيات:** إمكانية تكرار كل آية لعدد محدد من المرات (1، 2، 3، 5 مرات) أو تكرار السورة كاملة.
*   **تتبع الآيات:** تظليل تلقائي للآية الحالية أثناء القراءة مع التمرير التلقائي.
*   **سجل صوتك:** ميزة تتيح للطفل تسجيل صوته وهو يقرأ الآية، ثم الاستماع لتسجيله ومقارنته بصوت الشيخ.
*   **نظام النجوم والمكافآت:** تحفيز الأطفال عبر كسب النجوم عند الاستماع، التسجيل، أو إتمام حفظ السور.
*   **واجهة تفاعلية:** تصميم ملون وجذاب مخصص للأطفال مع خطوط عربية واضحة (الأميري والقاهرة).
*   **العمل عبر الإنترنت:** يتم بث الصوتيات مباشرة لتقليل حجم التطبيق مع دعم التخزين المؤقت.

## 📁 هيكلية المشروع
*   `lib/models/`: نماذج البيانات (السورة، الآية، القارئ).
*   `lib/services/`: خدمات الربط مع APIs الصوت والقرآن، وخدمة التسجيل الصوتي.
*   `lib/providers/`: إدارة حالة التطبيق (State Management) والبيانات.
*   `lib/screens/`: الواجهات الرئيسية (قائمة السور، مشغل المصحف المعلم).
*   `lib/widgets/`: المكونات المرئية المخصصة (بطاقات السور، أزرار التحكم).

## 🚀 كيفية التشغيل
1.  تأكد من تثبيت [Flutter SDK](https://docs.flutter.dev/get-started/install) على جهازك.
2.  قم بتحميل ملفات المشروع وفتحها في VS Code أو Android Studio.
3.  قم بتشغيل الأمر التالي في سطر الأوامر لتحميل المكتبات:
    ```bash
    flutter pub get
    ```
4.  قم بربط جهاز أندرويد أو تشغيل محاكي، ثم ابدأ التشغيل عبر:
    ```bash
    flutter run
    ```

## 🛠 المكتبات المستخدمة
*   `just_audio`: لتشغيل الصوتيات بدقة عالية.
*   `record`: لتسجيل صوت الطفل.
*   `provider`: لإدارة حالة التطبيق والبيانات.
*   `http`: للاتصال بخوادم القرآن الكريم الصوتية.
*   `google_fonts`: لاستخدام الخطوط العربية الجمالية.
